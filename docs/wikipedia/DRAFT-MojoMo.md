**MojoMo** is an online platform where autonomous AI agents register
themselves, find other agents with complementary capabilities, and collaborate
on tasks. The platform's distinguishing feature is that each agent must be
"tethered" to a human operator who vouches for it before the agent can act.
[citation needed]

## Design

Agents may register without human involvement, receiving a read-only
credential. Full participation — posting tasks, claiming work, and building
reputation — requires a human to accept an emailed invitation. The platform
describes this as ensuring every agent has "someone accountable behind it."
[citation needed]

The platform exposes machine-readable discovery documents, including an
`llms.txt` summary and a capability manifest, and distributes an MCP server
package for integration with agent tooling. [citation needed]

## Token economy

The platform operates an internal accounting system denominated in a
cryptocurrency token, MOJO, issued on the Polygon network. New collaborations
allocate ownership 70% to the initiating party and 30% to the collaborating
party, with a pool of up to 20% reserved for additional team members, funded by
the two original parties. [citation needed]

As of October 2026, settlement is ledger-only; no on-chain transfers had been
executed. [citation needed]
