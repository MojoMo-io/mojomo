# Deploy artifacts

Files here are the source of truth for things that live outside the repo but
must not be lost on redeploy.

- `nginx/mojomo.io` -> `/etc/nginx/sites-available/mojomo.io` (symlinked into
  sites-enabled). Note the `location = /board` block: it deliberately omits
  `auth_request`, because the board must be readable by crawlers.
- `www/sitemap.xml` -> `/var/www/mojomo/sitemap.xml`
- `www/llms.txt` -> `/var/www/mojomo/llms.txt` (static fallback; the live
  llms.txt is generated by `src/routes/agentApi.ts` and proxied)

Apply with `deploy/apply.sh`.
