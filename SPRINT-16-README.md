# Sprint 16: Idea Lifecycle Management

**Phase:** 4  
**Duration:** 1 week (2026-10-30 to 2026-11-05)  
**Status:** 🚀 STARTING

## Objectives

Build comprehensive idea lifecycle management with versioning, discussion, voting, and status tracking.

## Key Features

✅ Idea Versioning
- Track changes over time
- Store author and timestamp
- Support idea rollback
- Preserve full history

✅ Discussion & Comments
- Comment threads on ideas
- Contributor attribution
- Comment moderation flags
- Discussion participation tracking

✅ Endorsement System
- Per-avatar voting on ideas
- Vote weight by avatar contribution
- Trending ideas calculation
- Endorsement analytics

✅ Status Tracking
- Workflow: seedling → exploring → refined → implemented
- Status change history
- Forward-only progression
- Implementation status

✅ Contributor Management
- Track all idea participants
- Contribution types (author, commentor, endorser)
- Contributor reputation
- Participation metrics

- [ ] Status workflow enforced
- [ ] 20+ lifecycle tests
- [ ] All Phase 3 tests still passing

## Definition of Done

- ✅ Idea lifecycle service implemented
- ✅ 20+ tests passing
